# SAYO ARCHIVE｜佐代檔案館

## 使用方式
解壓後直接開啟 index.html 即可離線閱讀、搜尋和分類。網站為靜態 HTML，無登入、無伺服器、無外部字型或 JavaScript 依賴。

## 部署 GitHub Pages
1. 建立 GitHub repository（若使用公開 Pages，請確認內容可公開）。
2. 將本資料夾內的所有檔案及子資料夾放到 repository 根目錄，保留相對路徑。
3. 在 repository Settings > Pages 選 Deploy from a branch，選 main / (root)，儲存。
4. 部署成功後，使用 GitHub 提供的網站網址。將 /llms.txt 或個別 /cards/xxx.md 的公開網址提供給 AI。

## AI 讀取示例
「讀取我的佐代資料庫 llms.txt 和文津館初始角色卡。新開故事，不讀劇情分支。」
「讀取雪路客初始角色卡及 snow-injury 分支，依存檔續寫。」
注意：不同 AI 或瀏覽工具未必能開啟所有網站，請測試公開 URL；也可直接上傳 Markdown。AI 不會自動定期讀取網站或回寫存檔。

## 更新
- cards/：各 AU 初始卡，初始卡不因故事改變。
- branches/：獨立劇情分支，請用唯一檔名保存。
- reference/：寫作規則、配角參考、核心角色卡、存檔模板。
- 每份檔案都有 Markdown 和靜態 HTML。修改時請同步更新兩者，以及總索引、archive.md、archive.html、archive.json（若使用）。初版未附線上編輯／自動同步功能。
- llms.txt：AI 專用閱讀索引，新增卡片時記得加入。archive.md / archive.html / archive.json 為全庫匯出，含劇透，不能作為新故事的唯一讀取來源。

## 來源與限制
整理自截至 2026-11-25 當前可取得的使用者創作設定與對話摘要，並非已逐字核對所有歷史聊天。三筆初始卡目前只有名稱或簡短索引；劇情分支多為摘要，完整原文、最後停筆場景待補。沒有擅自補寫缺失設定。本網站為初版檔案，尚未代為發布。

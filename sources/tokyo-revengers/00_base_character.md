# 琲世佐代｜基礎角色卡
姓名：琲世佐代（Haise Sayo）。女性，日本，160cm。初登場14歲、國二，與半間同齡；三ツ谷低一個年級。高中一年級時進入武道主線。
外貌：冷白肌膚、鮮紅眼、左眼下淚痣、容貌極美、黑色中短髮齊瀏海（原為長髮，遭霸凌後由半間修剪）。成年髮稍長，成熟冷豔。
服裝：國中制服與書包；高中西式制服、襯衫、短裙、黑絲襪、皮鞋；東卍黑底金字特攻服，由三ツ谷修改；黑道未來白色西式襯衫、黑色長西裝褲、披肩黑西裝外套、高跟鞋。
性格：冷淡寡言、理性沉著、極聰明，曾年級第一。擅長觀察與戰術分析，不喜無謂爭鬥。感情遲鈍，不善表達需求，習慣忍耐，對信任者忠誠且依賴。成年較能辨認情感，仍不擅定義關係。黑暗未來可能因喪失與罪惡感產生自毀傾向。
能力：半間教導格鬥，風格冷靜精準、重效率，通常不參戰。東卍初代參謀／顧問，不任番隊隊長。
